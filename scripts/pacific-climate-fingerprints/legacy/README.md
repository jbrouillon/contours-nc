# Legacy prototypes

These files document early versions of the visualisation and are not loaded by
the published page.

- `climate-map.js` and `ribbon.js` are superseded browser prototypes.
- `export.R` depends on the missing `sst_warming.r`, `st_warming.r` and
  `rainfall.r` scripts. Its useful export logic is now covered by
  `../prepare_climate_data.R`.
